AI Voice Receptionist

● Live in production at a multi-practitioner health clinic in Victoria

An AI phone agent that answers every call when the clinic is closed. It takes booking, reschedule, cancellation and confirmation requests, answers common questions (location, prices, insurance), and texts callers a confirmation. Requests land on a web dashboard where the front desk works through them each morning.

  • Node.js / Express API that the voice agent calls as tools, with validation, shared-secret auth and graceful fallbacks
  • Business rules in code rather than the model: opening hours, holidays and time zones are calculated server-side
  • Merges follow-up details from the same call into one request instead of creating duplicates
  • Front-desk dashboard with login, urgent-first sorting, search, transcripts and per-request outcomes
  • Monitoring that texts me if a call goes silent or a request fails to save

SetsAndReps Gym Training Tracker

A full-stack web app for tracking strength training: live workout logging (exercises, sets, weight and reps), a rest timer, workout history, analytics charts, and a social feed for training with friends.

  • Normalized PostgreSQL schema (users, sessions, exercises, sets) with foreign keys, cascading deletes and unique constraints
  • Dashboard analytics built on aggregate SQL: joins, GROUP BY and conditional sums
  • Authentication with NextAuth, bcrypt-hashed passwords and per-user data isolation
